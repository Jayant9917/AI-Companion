# Desktop Dev Cat Documentation

This folder is the organized documentation source of truth.

## Reading order

1. `01-requirements-design` — business, product, and UI requirements.
2. `02-architecture-technical` — system architecture, technical requirements, low-level design, and repository structure.
3. `03-planning-implementation` — project plan, implementation plan, progress log, and deployment planning.
4. `04-assets-ui` — cat art, animation, sprite, and asset decisions.
5. `05-operations-handoff` — current development handoff and operational notes.

The `archive` folder contains older or superseded planning documents kept for history and reference.
