# Code of Conduct

## Our pledge

We are committed to making participation in this project a welcoming, respectful, and harassment-free experience for everyone, regardless of age, disability, ethnicity, gender identity or expression, level of experience, nationality, personal appearance, race, religion, or sexual orientation.

## Expected behavior

Examples of behavior that contributes to a positive environment include:

- Being considerate, respectful, and constructive.
- Welcoming different viewpoints and experiences.
- Giving and gracefully accepting feedback.
- Focusing on what is best for the project and its users.
- Taking responsibility for mistakes and learning from them.
- Respecting the privacy and security of other contributors.

## Unacceptable behavior

Unacceptable behavior includes harassment, discrimination, intimidation, personal attacks, sexualized language or imagery, unwanted contact, publishing private information, trolling, and any other conduct that would reasonably be considered inappropriate in a professional community.

## Enforcement responsibilities

Project maintainers are responsible for clarifying and enforcing this Code of Conduct. They may remove, edit, or reject comments, commits, code, issues, pull requests, or other contributions that violate this Code of Conduct, and may take other appropriate action when necessary.

## Reporting

Report unacceptable behavior privately to the project maintainer through the contact method listed in the repository owner's GitHub profile. Please include a description of what happened, relevant links or evidence, and any context needed to investigate. Reports will be reviewed as confidentially as practical.

## Scope

This Code of Conduct applies within project spaces and when an individual is officially representing the project in public spaces.
